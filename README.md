# FCaptcha for YunoHost

[FCaptcha](https://github.com/WebDecoy/FCaptcha) provides a self-hosted CAPTCHA
widget and a backend endpoint for verifying form tokens. The package builds the
native Go service and makes it available on a dedicated YunoHost domain.

**Status:** In progress. The release source, native Linux service, and package
schemas have been tested. The YunoHost install, upgrade, backup, restore, and
removal tests are pending.

See [administrator notes](doc/ADMIN.md) for the domain, credentials, and
installation constraints.
